# 🌍 Roamly - Travel Website

Roamly is a modern and responsive travel website built with React.js. It provides users with an attractive and easy-to-use interface to explore destinations, travel packages, local guides, and travel experiences.

## ✨ Features

- 🏠 Modern and responsive Home page
- 🌍 Explore travel destinations
- 🧳 Travel packages with pricing and details
- 📖 About Roamly page
- 🧑‍🤝‍🧑 Local travel guides
- 🖼️ Travel gallery
- 📩 Contact / Trip enquiry form
- 📱 Fully responsive design
- 🧭 React routing for multiple pages
- 🎨 Clean and modern travel-focused UI
- 🔗 Navigation between different website sections

## 📄 Pages

- Home
- Destinations
- Travel Packages
- About Us
- Travel Guides
- Gallery
- Contact

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Router
- Vite
